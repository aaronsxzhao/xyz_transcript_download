Noto Serif SC variable font (weights 200–900), Google Fonts v36.

Source stylesheet: https://fonts.googleapis.com/css2?family=Noto+Serif+SC:wght@200..900&display=swap

Font binaries are unmodified WOFF2 Unicode subsets from the stylesheet, renamed locally. Licensed under SIL Open Font License 1.1; see OFL.txt. Vite fingerprints the files, and the optional Editorial stylesheet loads only subsets needed for displayed text. No runtime request to Google Fonts is required.
